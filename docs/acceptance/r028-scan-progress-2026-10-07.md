# R028 检测进度与发布验收记录

记录日期：2026-10-07。源码版本：0.5.8。本文记录提交前的证据；后续 Linux CI、签名 Release 和生产验证须分别依据实际运行结果确认。

## 本批行为

- 环境体检显示真实固定检查项计数；文件阶段仅覆盖 root 纳管的程序与业务目录，未知总量不显示虚构百分比。
- 文件任务绑定独立任务 ID，展示当前文件、打开/摘要读取/引擎检测阶段、已读取摘要字节和最近 8 条结果。引擎内部进度未知时明确显示正在检测，不把摘要读取字节当成病毒引擎进度。
- 活动任务最多显示 99%；最终报告落盘后显示 100%。新请求被拒绝或等待本次任务报告时，不沿用上一次的 100%。联合检测同时展示完成数量和实际完整覆盖数量。
- 重启后的整体体检报告要求环境与文件任务共享身份；全部无任务 ID 的旧报告仍兼容，不接受新旧混合身份。
- 管理锁短暂竞争最多等待 15 秒；持续占用与 flock 系统错误分别报告，保留原锁及占用任务。
- 引入固定本机 Go 检测主控与四项就绪矩阵。缺依赖、缺库或缺可信证据仍显示未就绪；未新增三项依赖的自动安装、持续内核防护或自动文件恢复。
