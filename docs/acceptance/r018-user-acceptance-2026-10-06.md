# R018 铁幕安全用户操作验收

验收日期：2026-10-06。对象：独立安全仓库 candidate/v0.5.5 工作区及本地预览。运行版本为 v0.5.5；本次修改尚未发布或部署。

## 结论

本地登录、会话与十个页面的操作检查完成，发现并修复四类界面问题。Linux 生产验收未完成：生产浏览器访问遇到 ERR_CERT_AUTHORITY_INVALID；严格核对既有 SSH 主机身份后，现有 SSH 凭据认证被拒绝，没有执行远程命令。本报告不能作为生产查杀、病毒库、容器检查及面板更新通过的证据，也没有定位生产管理员登录失败的最终原因。

## 仍未达到完整企业级实机验收的事项

1. 生产面板可信 TLS 与实际管理员登录、会话恢复、退出。
2. systemd 宿主代理健康、套接字权限、真实 OS/软件/服务/端口及进程归属。
3. ClamAV 实际版本、官方病毒库有效性、隔离测试目录中的正常文件/EICAR 检测及结果证据。
4. 已纳管文件目录覆盖、逐文件真实进度、跳过原因、队列重启恢复及资源预算。
5. 容器权限、挂载、进程与可写层检查；当前代码不承诺所有镜像层/命名空间的全覆盖。
6. 网页隔离恢复、事件一键修复与不可变异地灾备仍有产品能力缺口。
7. 生产签名版本检查、更新服务、配置/身份保留及故障回滚。

处理顺序：恢复可信生产访问 → 实测代理与引擎 → 逐模块验证真实结果 → 需要时修复 → Linux 闸门 → 新签名正式版本 → 单独部署验收。
