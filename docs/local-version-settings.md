# 铁幕设置：版本校准与更新

v0.5.5 在独立铁幕面板增加「设置 · 版本与更新」。登录后可查看当前运行版本、安装记录版本、安装文件摘要、Git main 提交、最新正式版本、签名状态及真实任务结果。

点击「检查版本」读取 Git main 和最新正式 Release。系统也在启动约 5–10 分钟后检查，此后每 6 小时检查一次（带最多 5 分钟随机延迟）。Git 源码上传后在下一次检查显示；源码提交不等于可安装版本，正式更新必须提升版本、发布六附件并通过固定 Ed25519 公钥验签。

检查会按安装器同一算法核对程序摘要和安装记录。摘要不一致、网络失败、令牌无效、签名无效、降级或不完整附件会阻止面板升级。运行版本与安装版本不一致也会禁用安装按钮。页面不会将安装时间或重启时间伪造为进度百分比。

检查通过且发现较高版本后，15 分钟内可点击安装更新。更新任务重新检查签名，调用受控安装器获取正式包，再验证签名、SHA-256、安装事务及服务健康；成功后记录实际安装版本。更新可能暂时断开面板，重新登录后核对运行版本。超过 15 分钟需重新检查。

网页只能请求固定的检查或更新任务，经登录会话、同源与 CSRF 校验，通过仅允许指定 UID 的本机 Unix socket 交给 root systemd 服务。不能指定下载地址、Shell 命令、角色或任意路径。任务互斥，单次上限 32 分钟。记录和更新日志留在本机受保护目录，不返回令牌或私钥。

私有仓库复用 root 专属的 /etc/ironcurtain/github-release.token（600/400）；在 Linux 菜单维护凭据，不将 Token 放进网页。后台检查不是 Git webhook，不承诺提交后即时显示，也不默认自动安装。

Linux 原有命令继续可用：`sudo tiemu` 打开菜单；`sudo tiemu update` 检查并更新签名正式版本。

Windows 本机测试不能代替真实 Linux/systemd/Docker 验收；发布记录分别记录候选、正式版及制品回取证据。生产服务器升级单独确认实际运行结果。
