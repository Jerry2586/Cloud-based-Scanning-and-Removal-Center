# 文件引擎安装 / 修复

版本：v0.6.13。铁幕设置页提供“安装 / 修复文件引擎”，用于修复文件查杀依赖。支持范围仍受发行版受信软件源、网络与已安装版本约束。此动作不安装镜像漏洞、端口资产或行为探针依赖。

## 用户操作

登录铁幕，在引擎设置查看本机依赖，再点击安装 / 修复。页面显示实际排队、安装、完成、失败及中断状态；运行中每两秒查询状态，空闲时每二十秒查询。请求受理不表示成功。完成后重新检查引擎，并运行纳管目录的文件扫描；有元数据不等于文件全部干净。

首次安装走系统受信软件源，官方病毒库由隔离更新器下载。已切换玄武签名病毒库时，仅修复文件引擎的软件包，保留来源、签名、库文件与所有权，保持官方更新器停用。软件源、下载、库加载或签名来源异常均报告失败。

## 固定权限与互锁

网页 GET /api/engines/maintenance 和 POST /api/engines/install 使用既有认证会话；写入还核验 Origin、CSRF 和严格空对象。宿主 socket 只允许固定 /engine-maintenance 动作，安装请求不含正文。

代理核验 ironcurtain-engine-install.service 的 root 身份、oneshot、精确命令、无 DropIn、control-group 和超时。worker 校验当前发布回执，再执行发布中的固定安装器，不接受浏览器命令、路径、源或包名。独占管理锁阻止维护与扫描、程序更新等交错，worker 启动后再次取锁。

任务及维护日志在 /var/lib/ironcurtain/local/engine-maintenance，root 专属；面板只显示净化的固定状态，不回显安装日志或秘密。任务 ID、时间和状态均经合同校验，损坏显示不可用。十秒请求冷却不会把失败报成成功。

安装子进程最多执行660秒，超时终止进程组并等待回收后释放租约；systemd 另有12分钟启动与15秒停止上限。服务不 enable；恢复、升级和代理重启不重放维护，旧排队/运行任务显示中断，用户明确重试才创建新任务。

## 验收与限制

接口与合同回归验证认证、拒绝自定义参数、大小上限、任务状态与会话响应隔离。Linux root回归验证互锁、进程组超时、失败与中断重试；独立部署门禁使用真实 systemd、安装载荷和管理锁。来源修复门禁使用明确的软件源测试替身，不能当作真实病毒库验收。官方病毒库独立门禁实际下载 CVD、双重验签、mTLS 分发、激活，再通过受信 HTTPS 登录、维护接口与实际安装的 root oneshot 完成系统软件包修复；核验新任务身份、完成状态、库文件与来源保持不变，以及修复后的正常/EICAR 扫描。

实际执行结果见 [R034验收记录](acceptance-r034.md)。Windows平台跳过不计为Linux通过；本版生产网页部署仍单独验收。本能力不能承诺任意系统安装成功或整机绝对安全。
