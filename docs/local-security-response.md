# 铁幕本地处置与恢复边界

2026-10-05：独立项目已有有界文件隔离和恢复，R009 新增目录队列与重启后命中证据恢复。固定核验中的 response.containment 仍为 unavailable：尚无通用业务容器自动断网、进程终止或干净重建闭环。

## 当前可执行动作

铁幕检测并记录纳管文件、配置、固定宿主环境、容器与监听变化。深度任务提供真实文件计数，命中证据留在本机。root Linux 菜单 18 查看证据，19 显式隔离，20 查看记录，21 恢复隔离文件；网页只读这些记录。

隔离前重新核对证据与固定文件描述符，并执行真实病毒复扫。只处理受控范围中 root 管理的单链接普通文件；配置、凭据、数据库、系统/安全目录、共享可写文件与多链接文件拒绝处置。先复制、验证并落盘，再删除已核对的原文件。恢复校验隔离副本、不覆盖已有目标、以 root:0600 恢复并保留隔离副本。隔离不结束已运行的进程，也不能据此判断宿主已清洁。

安装和管理失败使用 root 私有事务快照恢复安全程序配置与身份。已实现同机同版本认证加密恢复，保留现行身份、CA 与撤销状态。这些备份属于安全软件自身，不包含任意网站数据库或产品数据的容灾承诺。

## 尚需实现与演练

1. 根据明确批准的容器和处置策略实施业务封控，保留 SSH 管理和取证通道。
2. 从独立验签的干净镜像/发布恢复程序，先备份、核对数据兼容和健康，再接管流量；失败可回退。
3. 宿主 root 失守时在干净服务器重建，不信任受疑主机新生成的基线。
4. 不可变异地副本、密钥分离、单写围栏及跨主机故障切换；通过恢复演练后才能给出 RPO/RTO。

## 云端边界

玄武登记/撤销节点，分发签名规则、官方库和正式程序。铁幕以独立身份主动拉取并在本机验签。云端不持有业务机 SSH，不远程删除文件，不发送任意命令。云端失联时本地扫描继续；云端异常时解绑和撤销身份，未验签数据不能启用。
