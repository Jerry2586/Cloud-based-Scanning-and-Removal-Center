# 本地处置与恢复：迁移边界

2026-10-04：APPGOG 内嵌处置实现已保存到独立项目，历史业务专用脚本暂作为迁移来源，不属于新铁幕通用处置入口。独立扫描中的 response.containment 当前返回 unavailable。

## 当前可以执行的动作

铁幕检测并记录文件/配置/环境变化、展示扫描与历史证据。管理员可在独立 Linux 菜单停止铁幕、解绑玄武、重置面板密码；玄武可以撤销节点身份。这些动作针对安全系统自身，不代表已隔离受攻击业务。

安装失败及管理配置失败使用私有事务快照恢复原配置与身份。原本停止的服务保持停止，原本运行的服务需恢复并健康验证。失败恢复记录保留供重试。此能力服务于安全软件维护，不是网站恶意文件清理或业务数据库容灾。

## 通用响应目标与接入门槛

1. 以报告中的 finding、可信基线和变化证据创建事件，明确受影响项目及检查范围；单次差异先告警，不自动删除文件。
2. 本机管理员预先批准项目、容器及有限处置策略。只隔离明确关联的目标，保留 SSH 管理与证据目录。
3. 文件隔离需拒绝符号链接、设备、路径逃逸及扫描后内容变化；记录原路径、摘要、元数据和事件编号。
4. 误报恢复需重新验证隔离物、确认原路径未被覆盖并审计；业务数据库和数据卷不由杀毒接口删除。
5. 程序修复从独立验签的版本恢复，先备份并确认业务兼容，失败可回退。
6. 宿主 root 失守时用干净服务器重建，避免把被污染主机的当前文件作为恢复基线。

这些通用动作必须配合真实 Linux 对抗与恢复测试后才能开放网页按钮。旧 APPGOG 脚本中的目录、容器名、备份格式及围栏逻辑需要逐项适配，不能直接套到任意网站。

## 云端与容灾

玄武保留核对、身份及证据边界；本地拉取已签名且满足本机策略的发布和规则。云端不发任意命令、不远程删除、不持有业务主机 SSH。

独立不可变备份、密钥分离、恢复点选择、单写围栏及跨主机故障切换仍是待建设能力。RPO/RTO 只有经真实恢复演练后才能给出达标结果。本机私有事务快照不能替代异地灾备。
