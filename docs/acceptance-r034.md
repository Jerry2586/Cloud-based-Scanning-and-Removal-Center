# R034：铁幕与玄武验收记录

日期：2026-10-08。代码版本：0.6.5（v0.6.4 双端生产验收已完成）。范围为现有功能、界面交互和运行维护；源码、正式包及生产部署分别记录。

## 当前结论

现有接口和独立文件查杀链路有真实验证证据；整个企业级 PRD 尚未合格。生产当前未配置业务目录/容器保护范围和可信文件基线，玄武尚无有效签名规则、签名官方库或外部情报凭据。这些情况保留为未知、覆盖不足或未就绪，不报告全面安全。

## 已修复并回归

- 云端节点、检测来源自动刷新保持阅读展开与键盘焦点；节点展示身份、认证上报、探测、完整性、宿主检查及下一步。
- 审计分开显示排队、执行、部分完成、失败和重新排队，任务受理不再显示检测成功。
- 铁幕主机与容器页保留主要资产、容器和端口，将软件服务详情、检查证据、完整报告分层展开，保留报告绑定。
- 域名读取失败显示明确不可用状态，禁用重复提交；连接恢复后显示实际地址/证书并恢复可用操作。
- 签名规则 503 和节点认证失败给出固定故障指引；不回显远端正文、秘密或路径，保持验签和高水位。

Windows Node 全量 252 项：196 通过、56 Linux 平台跳过、0 失败。Linux root、Go race/vet、真实 Docker/systemd、签名事务与真实引擎仍必须在该提交的候选及正式门禁运行，不把平台跳过计为通过。

## 尚未达到的商业能力

- 生产业务目录、容器、端口允许清单和可信发布基线：需要从已确认保护范围与可信发布建立；不能把当前磁盘内容自动视为干净基线。
- 本机镜像漏洞、端口资产与行为探针在现有生产环境未就绪；持续监测目前为有界周期检查，不是完整实时 EDR。
- 玄武规则、签名官方库、外部情报的真实生产来源待配置；插件目前是固定目录，尚非任意镜像插件商店。
- YARA/Tetragon/CrowdSec/SPA、AI 自动规则治理、通用漏洞自动修补、网站秒级业务回档和异地灾备尚未完整实现。

生产升级后需核对配置、身份、保护范围、原密码、代理/控制服务与 APPGOG 容器基线未变化。正式结果以六附件回取验签和实机后检查分别报告。
