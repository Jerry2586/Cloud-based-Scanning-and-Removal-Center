# 铁幕本地主机网络与内核检查

独立铁幕宿主代理每 300 秒进行固定环境核验，独立安全面板展示时间、范围、结果与历史。Linux 菜单 8 提交环境核验，菜单 31/34 发现或查看监听与容器对象。文件深度任务运行时暂停周期核验；旧核验过期必须显示。检查只读，不修改路由、防火墙、内核参数或关闭 SSH。

## 当前独立实现

- TCP/UDP 监听：通过固定 ss 参数读取宿主监听，与 profile 中管理员配置的端口允许名单比较。新发现模块同时记录监听地址、PID 和进程名，与上次有效观察比较；命令失败或格式异常显示不可用。绑定端口不等于公网可达。
- 路由：读取 ip -j route show 的快照摘要。当前独立实现缺少可信路由批准流程，因此返回 warning 提醒复核，不能显示路由可信。旧 APPGOG 的 network-fingerprint/approve-network 菜单不适用于独立项目。
- 内核：只读核对固定安全参数，弱值显示 warning，读取失败显示 unavailable；不自动写 sysctl。
- 防火墙：独立代理采集可用的运行时规则摘要；当前缺少可信规则批准和完整策略分析，保持待复核状态。历史业务项目的防火墙批准入口不能作为当前产品能力。

## 范围与后续建设

宿主快照不能覆盖所有容器网络命名空间、策略路由、云安全组或证明公网访问路径。容器 host network、host PID、特权及敏感挂载另由宿主发现模块记录。发现变化不能自动学习为可信配置。

后续需要独立的路由/防火墙基线批准、规则差异、实际可达性核验和受控封控策略。当前网页与云端不能写规则或执行任意命令。文件队列与发现预算见 [宿主发现与深度查杀](local-host-full-scan.md)；能力与测试证据见 [验收矩阵](capability-status.md)。
