# 铁幕安全 · 玄武引擎 v0.5.3

两端 Linux 菜单此前执行选项后立即重画首页，操作结果与证书提示被挤到上方。本版本让成功和失败结果都停留显示，按回车后才返回菜单；终端断开或 Ctrl+D 时正常退出。

菜单编号允许首尾空白，空输入和无效编号在当前提示处重试，不重复刷新首页。编号内部的无效字符和当前角色未显示的选项不会执行。密码、身份包路径等业务输入不受编号处理影响。

直接命令（例如 tiemu status、xuanwu reader 和两端 update）仍执行后退出，适合脚本调用。原菜单编号、角色、身份、数据路径及 ironcurtain 兼容入口保持一致。

## 更新与打开

铁幕服务器：

~~~sh
sudo tiemu update && sudo tiemu
~~~

旧版本缺少 tiemu 时可使用 sudo ironcurtain update，然后再打开 tiemu。玄武服务器：

~~~sh
sudo xuanwu update && sudo xuanwu
~~~

玄武菜单 11 的浏览器证书路径与指纹会停留，方便通过可信管理通道取得证书。网页客户端证书与令牌验证保持启用。

## 验收范围

真实 Linux Docker 部署闸门通过 PTY 验证两端状态、玄武证书提示、铁幕未配对失败、空白/无效编号、角色限制及 EOF。测试先观察没有输入时结果保持，再显式发送回车检查只返回一次；直接命令不增加等待。

正式发布需通过候选三组 Linux 闸门、六附件验签、正式重复闸门及独立回取验签。发布记录不能代表生产服务器已经升级。
