# v0.6.3 · 面板密码管理

本版本为铁幕和玄武补齐 Linux 菜单修改面板密码，并为玄武新增用户中心。

- 菜单 14 支持自定义密码和随机重置。可直接运行 `sudo tiemu password` 或 `sudo xuanwu password`；新密码隐藏输入并要求再次确认，root 管理员忘记旧密码也可恢复。
- 玄武网页顶部及侧栏增加用户中心，校验当前密码、新密码和确认；成功后退出登录。日夜主题均支持。
- 修改后废止旧会话，运行凭据与 root 恢复副本原子更新；初始密码提示文件不继续保存明文旧密码。
- 固定账号控制服务使用 Unix 身份校验、受限接口、管理锁及事务恢复；安装升级检查真实服务和 socket 可用。
- 同机备份、恢复与管理事务同步停止和恢复账号及域名控制服务，避免配置目录替换后服务继续使用旧的受限目录。
- 发布包包含账号控制器与客户端；部署门禁覆盖隐藏输入、错误确认、CSRF、旧密码/会话失效以及服务和容器重启。

发布前验证：Windows Node 246 项，190 通过、56 平台跳过、0 失败；隔离 root Linux 账号事务 13/13 通过。Linux 完整 CI、签名六附件、正式回取验签与生产部署分别记录，未执行的检查不记为通过。
