# 铁幕安全 · 玄武引擎 v0.5.4

玄武菜单 8「登记节点与加密导出」不再要求管理员手动设置解锁密码。每个节点通过 OpenSSL 随机生成独立的 256 位秘密，显示为 64 字符十六进制密码；加密身份包仍使用原有 AES-256-GCM 封装与身份校验。

密码只在可信交互终端显示，并单独保存在加密包旁的 `.icpair.unlock` 文件中，目录权限 700，文件 root:root、600。密码不进入运行时挂载、管理审计、节点配置或命令行参数。铁幕菜单 10 粘贴生成的密码、核对玄武 CA 指纹，真实 mTLS 握手通过后提交身份；原有身份包继续支持导入。

自动密码只改变创建身份包的操作。首次配对、每节点独立身份、签名更新与本地管理权限边界沿用既有流程。密码和加密身份包需要分开保管和传递。

Linux 部署闸门覆盖实际菜单登记两个节点、密码独立性与文件权限、错误密码拒绝、实际铁幕导入与 mTLS 握手，以及重复节点拒绝后保留既有身份。
