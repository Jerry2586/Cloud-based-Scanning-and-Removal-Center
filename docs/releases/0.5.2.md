# v0.5.2：统一 Linux 管理菜单排版与提示

铁幕与玄武的 Linux 菜单改为双线边框标题、版本与安装目录、清晰状态区及每行一个编号选项。支持颜色的终端显示蓝色标题和状态颜色；非交互输出、TERM=dumb 或 NO_COLOR 环境使用无颜色文本。中文标题按显示宽度对齐。

铁幕默认状态页将病毒引擎的原始 JSON 改为中文摘要，区分未就绪、病毒库需要更新和元数据已配置；元数据存在不代表实际扫描已成功。详细引擎数据仍可从原选项 17 查询。玄武显示实际登记节点数。

安装结束明确提示输入 tiemu 配置受保护项目与玄武连接，玄武提示输入 xuanwu 登记节点。同步修正本地页面账号提示和玄武程序更新说明中的遗漏命令。

## 更新与菜单

旧版本地节点先执行：

~~~sh
sudo ironcurtain update
~~~

升级成功后使用 sudo tiemu 打开菜单；后续更新可用 sudo tiemu update。玄武执行 sudo xuanwu update，更新后使用 sudo xuanwu 打开菜单。

原菜单编号、动作、身份与数据路径保持兼容，旧 ironcurtain 命令继续可用；固定发布公钥、引导器及签名合同保持一致。

## 验收范围

真实 Linux 部署闸门增加两角色竖排菜单、边框、颜色与无颜色输出、中文宽度对齐、默认状态无原始引擎 JSON，以及当前命令提示检查。发布须通过三组 Linux 质量闸门和六附件独立回取验签；不代表用户生产服务器已升级。
