# 铁幕安全 · 玄武引擎 v0.5.5

铁幕新增「设置 · 版本与更新」：显示当前运行和安装版本、安装文件摘要、Git main 提交、最新签名正式版本、检查时间及真实后台任务结果。支持手动校准、每 6 小时定时检查和管理员显式更新。Git 上传的源码变化单独显示，可安装版本来自六附件完整、Ed25519 验签通过的正式 Release。

更新经会话、同源和 CSRF 校验进入固定本地 systemd 任务；不接收任意命令或下载源。安装前重验签名和摘要，拒绝降级或不一致安装，更新沿用事务备份与恢复。安装/备份恢复保留检查定时器状态及铁幕菜单别名。

环境监测增加真实 dpkg/RPM 软件、systemd 服务、OS/内核观测，以及容器和监听历史变化展示。首次观测不作为可信批准基线；依赖缺失、预算截断和覆盖不完整明确显示。采集记录与敏感路径留在本机，公开面板仅返回有界过滤数据。

本地新增「一键全面体检」：先采集 Linux、软件、服务、端口、容器，再使用本机 ClamAV 扫描已纳管文件。玄武配对为可选；缺引擎、有效病毒库或范围时继续环境检查并显示未完整覆盖。阶段、计数、进度与完成状态绑定同一次真实任务；进程中断、过期记录及错误保持可见。

新增「杀毒引擎」页面，显示实际引擎版本、病毒库版本、时间、特征数和更新来源。官方直接病毒库可通过固定本机更新服务更新，无需玄武；签名分发来源保持独立验签，不混用。

发布闸门包括 Linux 权限/签名/归档事务、实际双角色 Docker 安装升级、HTTPS 设置接口、CSRF 拒绝、实际 systemd 校准以及未配对本机全面体检、真实 ClamAV 两文件命中与保留，以及既有 mTLS 验收。用户生产服务器未自动升级。跨机灾备、内存/内核 EDR 与所有存储驱动完整覆盖不在本次交付承诺内。
