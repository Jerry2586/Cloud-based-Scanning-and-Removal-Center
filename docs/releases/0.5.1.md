# v0.5.1：统一 Linux 管理菜单入口

铁幕菜单的日常命令改为 `tiemu`；玄武继续使用 `xuanwu`。安装完成与重复安装提示、菜单标题、网页面板地址及更新说明同时统一。已有保护对象、身份、数据和服务标识保留。

## 安装后的菜单

铁幕：

~~~sh
sudo tiemu
~~~

玄武：

~~~sh
sudo xuanwu
~~~

## 旧版升级

已安装旧版铁幕的服务器，先执行：

~~~sh
sudo ironcurtain update
~~~

升级成功后可用 `sudo tiemu update` 日常更新；旧 `ironcurtain` 命令继续可用。玄武仍用 `sudo xuanwu update`。

签名合同保留旧入口名，兼容已有固定引导器；不更换发布公钥、服务、容器、配置路径或证书。新 `tiemu` 入口纳入安装快照与回滚，旧版本未完成事务仍按原入口恢复。
