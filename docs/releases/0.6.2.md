## 验收边界

本版本提供固定检查调度和状态可靠性。它不把缺失的 ClamAV、Trivy、Osquery、Falco、病毒库、可信基线或云端连接显示为可用，也不提供网页任意 root shell。Windows 预览只验证合同和 UI 降级，不代表 Linux 宿主扫描；Windows 无 cgo 时不宣称 race 结果。真实 Docker/systemd、Linux race、签名安装包、六附件回取验签和玄武生产升级必须在 CI/正式环境单独记录。
