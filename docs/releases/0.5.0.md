# IronCurtain / Xuanwu v0.5.0

本版本将已验收的 R009 本地宿主发现与文件深度查杀纳入独立安全项目安装载荷。铁幕和玄武使用同一程序版本，仍分别选择 local/cloud 角色；APPGOG 的业务发布与数据不属于此版本。正式状态以 GitHub Release、对应提交和六附件回取验签结果为准。

## 新增能力

- 发现宿主监听进程、Docker 容器权限/挂载/进程/可写层变化和应用目录候选；缺工具、预算超限或存储驱动不支持时显示覆盖缺口。
- root 菜单按候选序号显式纳管目录，事务切换并检查代理健康；发现不自动批准镜像、端口或文件信任基线。
- 真实 ClamAV 文件队列，使用固定文件描述符，显示 indexed/processed/clean/infected/skipped/errors 和扫描字节数。
- SQLite 队列保存扫描进度与有界命中证据；范围或病毒库 generation 改变时拒绝复用旧队列，代理重启恢复暂停状态。
- Linux 菜单 31 发现环境、32 纳管目录、33 深度扫描、34 查看计数；网页只提交无参数固定扫描操作。
- 扫描接口明确区分已接受、运行中、忙碌、429 冷却和代理不可用；异常上游状态拒绝处理。

## 安装与升级

已安装独立铁幕：`sudo ironcurtain update`。玄武：`sudo xuanwu update`。首次安装使用 README 对应角色的一行命令，自动补齐支持范围内的环境并识别公网 IPv4。安装提示须显示签名清单与安装包摘要验证成功，版本为 v0.5.0。

安装/升级复用既有地址、角色配置、身份和状态路径；运行原有快照、事务恢复与健康检查，不替换宿主 Docker 全局配置或已发布旧版本附件。完成后输入 `sudo ironcurtain`，先检查引擎和病毒库，再发现并显式纳管需要保护的目录，最后执行深度查杀。未纳管、未加载有效库或扫描存在跳过/错误时不能标为完整覆盖。

## 验收与限制

R009 功能提交已通过 Linux CI 37282725180，文档最终提交通过 37283213787。v0.5.0 按既定发布策略重新运行候选三组 Linux gate、签名附件回取，以及正式发布闸门。真实 Docker/systemd 安装/升级与真实 ClamAV 独立测试特征库验收分别报告；本次不冒充官方公网病毒库下载、用户生产主机或跨主机验收。

文件查杀仅覆盖显式纳管范围；逐文件 clamscan 加载大病毒库较慢，尚无常驻 clamd。没有完整内存/内核查杀、实时 EDR 自动封控、CF 自动修复或跨服务器业务容灾。安全软件和病毒库健康不等于整机绝对安全。细节见 [本地宿主发现与文件深度查杀](../local-host-full-scan.md) 与 [能力矩阵](../capability-status.md)。
