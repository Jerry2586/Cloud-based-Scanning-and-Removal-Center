# 铁幕本地处置工作台

版本：v0.6.12。新增网页保护对象发现与纳管；本版验证以对应候选、正式签名 Release 和回取报告为准，生产服务器升级与网页验收另行记录。下方 v0.6.11 工作流为历史证据，不代表 v0.6.12 已通过。

## 页面职责

扫描页负责启动、暂停、继续和查看真实扫描进度。环境页负责保护对象发现与纳管、主机/容器/端口资产及端口检测白名单。风险页汇总证据、展示覆盖和处理状态，并提供命中文件隔离入口。隔离与恢复页集中显示文件操作历史及原内容取回，设置页保留本产品更新、账号和连接配置。

风险的“待处理”“处理中”“接受风险”是人工受理状态，检测严重程度保留。新证据或超过有效期限会使旧受理失效；关闭浏览器不会取消已受理的宿主动作。报告来源缺失、过期、引擎不可用或列表截断会显示具体覆盖情况，不表示全机安全。

## 六种固定动作

| 动作 | 输入 | 实际效果 |
|---|---|---|
| 发现保护对象 | 无附加参数 | 固定宿主发现，保存两分钟有效的目录、容器候选及身份；覆盖缺失保留说明 |
| 启用保护范围 | 配置版本、发现摘要、1–32 个候选 ID | 核验目录及容器身份，原子追加保护范围、固定重启代理；启用失败恢复旧配置，需重新扫描 |
| 端口检测策略 | 页面读取的配置版本、TCP/UDP 整数列表 | 写入检测允许清单并固定重启代理，需重新检查监听；不关闭端口、不变更防火墙 |
| 风险受理 | 风险 ID、证据摘要、状态、4–240 字原因 | 仅保存与新鲜证据绑定的人工受理决定，不把告警当作已修复 |
| 文件隔离 | 命中文件证据 ID、明确确认 | 使用现有宿主证据约束重新核验文件身份和字节，复制、校验、落盘后移除原路径；不结束已有进程 |
| 原内容取回 | 隔离记录 ID、明确确认 | 不覆盖目标，取回 root:0600 原内容并保留隔离副本；原内容仍可能有害，需再次扫描 |

网页不能传递任意路径、shell、服务名、镜像名或远程目标。配置、凭据、数据库、系统与安全程序目录受原宿主约束保护；共享可写文件不在自动隔离范围内。玄武失联不影响本机处置服务，APPGOG 无依赖或生命周期耦合。

## 宿主与事务

非 root 网页通过只读挂载的 Unix socket 访问独立 ironcurtain-operations-local-control.service。服务使用 SO_PEERCRED 只接受 root 或精确 UID/GID 10001，限制请求/响应字节和固定动作。持久化状态位于 root 私有目录，与扫描、程序更新和管理操作共用独占管理锁。并发或待恢复事务会明确拒绝新操作。

端口配置与保护范围配置使用 prepared/applied/committed 持久阶段，文件与目录 fsync。启用失败恢复旧配置；崩溃后由控制器启动或管理事务入口核验恢复。外部修改或损坏事务保留现场并停止，不能覆盖猜测的配置。操作任务和审计原子持久化，服务重启将未完成任务标记中断；中断后的文件操作应核对隔离记录和实际文件再重试。

保护范围只允许从当前发现候选中追加；目录逐层拒绝符号链接，并核对设备/inode，容器重新核对名称、容器 ID 与镜像 ID。纳管不会批准镜像、文件基线或端口，也不会把未就绪引擎变成可用。过期候选、外部配置变更和复核超时均拒绝。

被动轮询保留未提交草稿和输入焦点；新配置版本不会直接覆盖正在编辑的列表。提交后旧 GET 结果失效，会话退出后在途响应不能回填页面。

## 验证边界

Node 测试覆盖固定动作合同、鉴权、客户端响应、过期版本和页面状态交接。Linux root 测试使用真实文件、锁和 Unix 对端身份，固定服务重启用替身，不冒充 systemd 验收。独立部署测试从真实签名载荷安装 Docker/systemd，实际 UID 10001 提交端口策略并确认代理重启，再恢复原策略；同时检查未授权身份拒绝、socket 目录 inode、容器挂载、失活服务升级恢复及加密备份恢复后的控制器可用性。

候选工作流 [37882757578](https://github.com/Jerry2586/Cloud-based-Scanning-and-Removal-Center/actions/runs/37882757578) 的接口/事务、真实 Docker/systemd 部署、真实 ClamAV 引擎三项质量闸门及候选签名均通过。六份候选附件已回下载并独立验证 Ed25519 签名、SHA-256 与版本；这些证据不替代正式 Release 回取或生产服务器验收。

可信干净业务快照恢复、异地不可变灾备、自动漏洞修补及实时内核阻断不属于这六个动作，仍需独立实现和验收。不能用容器健康、任务结束或处置受理代替这些能力。

本版新增部署验收通过实际 HTTPS 登录、目录/容器发现、纳管、代理配置摘要和重启确认检查接入；跳过引擎的安装应返回文件扫描不可用。真实 ClamAV 验收使用隔离测试特征库，验证纳管后的目录进入文件队列，并分别检出正常文件与命中文件；不替代官方病毒库公网获取或生产整机覆盖验收。
