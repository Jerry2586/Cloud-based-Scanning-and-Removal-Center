# 铁幕独立面板与玄武面板

铁幕不再挂在 APPGOG 授权后台。部署后通过独立 HTTPS 端口 8790 访问，独立管理员身份登录；玄武 HTTPS 端口 9443 的 /dashboard 使用 reader 客户端证书和登录凭据。

| 页面 | 当前行为 |
|---|---|
| 安全首页 | 盾牌、真实报告覆盖与问题计数；缺报告显示未就绪 |
| 病毒查杀 | 固定范围检查任务、真实完成项进度及 ClamAV 结果 |
| 实时防护 | 固定周期巡检结果及服务状态；不虚构入侵阻断 |
| 环境检查 | 系统、SSH、权限、监听端口、路由、防火墙等固定项 |
| 网站与容器 | 程序/配置基线、容器合同、镜像身份、SQLite 结果 |
| 隔离区 | 通用记录与恢复动作仍待接入，破坏性按钮禁用 |
| 修复与恢复 | 通用处置仍未接通；不显示修复成功 |
| 备份容灾 | 独立异地灾备与演练待开发，不连接 APPGOG 备份按钮 |
| 防护日志 | 本机代理真实变化与不可用历史状态 |
| 设置 | 节点连接、玄武身份和报告状态；管理动作使用 Linux 菜单 |

所有扫描按钮调用 /api/scan。POST 需要登录、有效 CSRF，且只能提交空对象；网页不能传路径或命令。收到代理实际 running 状态才显示运行进度，检查总数为固定合同数量，文件数只取引擎统计。登录失效时清除旧报告。

Linux 菜单：sudo tiemu 配置保护范围、配对、扫描、诊断及更新；sudo xuanwu 登记/撤销节点、查看 reader 指引及更新。业务网站若后期嵌入独立面板，仍需独立认证、来源限制和审计，不共用业务管理员秘密。

Windows 本地界面可以预览，但没有 Linux 宿主代理时扫描明确不可用；预览不证明正式部署完成。

玄武菜单 8 登记节点时只需输入唯一节点名称，系统自动生成 256 位随机解锁密码并仅在可信终端显示；独立备份为加密包旁 root:root、600 权限的 `.icpair.unlock` 文件。铁幕菜单 10 仍需粘贴这个密码并核对 CA 指纹，通过实际 mTLS 握手后才提交身份。不要将明文密码与加密包一起公开分发。
