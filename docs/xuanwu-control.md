# 玄武控制与摘要分析

本页描述 0.6.0 候选源码的实际合同。正式状态以 GitHub Release 和独立回取验签记录为准；代码提交、CI 通过、正式发布和服务器部署是不同证据。

## 工作台与职责

玄武提供安全总览、节点中心、引擎与特征、策略中心、检测任务、操作审计和系统设置。铁幕保留离线文件查杀、主机体检和容器检测能力；云端不可用不阻止本机扫描。网页显示检测能力名称，来源详情保留真实来源和许可。

玄武浏览器管理入口默认使用 HTTPS 8791，节点证书认证入口使用 mTLS 9443。管理员会话使用独立密码、CSRF 和同源校验；节点必须同时通过私有 CA 客户端证书和自己的独立 Token。节点只能查询自己发起的任务。

## 固定插件目录

| 插件 | 实际作用 | 就绪条件与边界 |
|---|---|---|
| 文件特征规则 | 将 SHA-256 与独立签名特征比对 | 验签通过、未过期的规则；未命中保持未知 |
| 文件查杀病毒库 | 存储、验签及认证下发官方文件病毒库，由铁幕本地执行文件扫描 | 独立发布签名和官方库验签均通过；不能只凭文件 Hash 调用全文件病毒扫描 |
| 云端哈希情报 | 查询固定 VirusTotal v3 文件摘要端点 | 管理员配置服务端只读密钥、安装并启用插件，策略允许外部查询；商业使用须具有对应许可 |

安装是启用已实现的固定适配器，不接受任意镜像、脚本、URL 或插件上传。暂停和移除不删除已完成任务中的历史证据。外部查询只发送 SHA-256，不上传样本；禁止重定向和用户指定地址。密钥由 root 在运行配置目录维护，Web 接口不返回密钥。

每个服务实例的外部情报查询预算为每分钟最多 4 次，响应最多 256 KiB，只接受对应摘要、合法统计值和最近 30 天的分析结果。配置存在表示连接器已配置，真实任务仍可能因账号配额、授权、网络或数据过期而返回不可用。

## 检测任务与裁决

管理员或认证铁幕提交 SHA-256 和 UUID 请求编号。相同身份与请求编号重试复用任务；改用不同摘要返回 409。每次任务保存当时的策略修订和插件列表，结果包含来源、规则版本或情报时间、状态及裁决原因。

完整性报告中新增或变化文件的有效摘要可以自动提交，每份报告最多 8 个摘要。同节点、摘要、策略和插件组合在 10 分钟内复用持久记录。没有启用且就绪的摘要插件时显示不可用；队列满显示延期或部分调度。节点上报的摘要只是待分析证据，不等于证明文件恶意。

默认外部查询关闭，默认恶意情报阈值为 3；管理员可在 1–20 内设置。签名恶意特征命中可得出恶意裁决；外部命中达到阈值为恶意，低于阈值但有风险报告为可疑，其余保持未知。全文件、内存和行为覆盖不由 Hash 裁决替代。自动隔离、封禁和文件恢复均不由该任务执行。

## 持久化与资源预算

SQLite 使用 WAL、FULL 同步和事务，将插件、策略、任务与操作审计写入独立状态目录。数据库权限为 0600。队列最多 256 个待处理任务、每身份最多 32 个；并发 2，单任务预算 8 秒。历史保留最多约 2000 个已结束任务和 5000 条审计事件，工作台投影最近 100 条。

重启将未结束的 running 任务恢复为 queued 后重新处理，已完成结果、插件状态和策略修订保留。存储暂时失败时自动重试，退避从 1 秒增长到最多 30 秒，恢复过程保持任务待处理并显示工作进程错误；不会把持久化失败写成完成。服务退出会停止重试、取消在途来源请求并关闭数据库。目录创建前后均核对所有者、写权限与符号链接；同 UID 或 root 已失陷不由这些检查提供隔离保证。工作台写入策略必须带当前 revision；并发变更返回 409，防止覆盖。审计是本机可追溯记录，尚未实现跨机防篡改归档。

## 验收与后续能力

自动化检查覆盖严格请求和响应合同、mTLS 和独立 Token、节点任务隔离、登录/退出、CSRF/Origin、策略冲突、幂等与不同摘要冲突、真实未知裁决、签名规则命中、外部查询故障、资源预算和重启持久化。Docker 部署探针会验证 SQLite 权限、服务重启后的状态和真实 HTTPS 管理接口；Linux 结果以对应 CI 为准。

跨服务器铁幕接入和真实官方库下发须另外验收。当前未实现任意插件商店、SPA 敲门、AI 自动写规则、云端任意命令、全功能 EDR、业务文件自动快照恢复或异地灾备。后续开发需继续保留每节点身份、固定权限、签名更新、明确覆盖范围和失败可恢复合同。
