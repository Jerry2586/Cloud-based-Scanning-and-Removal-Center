### R031 固定周期检查与维护互锁（v0.6.2）

R031 为铁幕本地主机代理增加三个固定任务：快速环境体检、已纳管目录的文件深度查杀、本地联合检测。网页只能提交已定义任务的启用状态和受限周期；不能提交路径、镜像、命令或自定义脚本。配置、任务编号、尝试次数、开始/结束时间和中断状态写入 root 私有状态文件，代理重启后恢复为可核验的 `interrupted` 或 `deferred`，不会把未完成任务显示为完成。

维护、病毒库更新和其他管理事务持有同一管理租约。租约期间周期任务延期，`dispatching` 或 `running` 时拒绝修改周期配置；任务启动失败会释放租约并保留失败证据。网页通过同源会话、CSRF 和本地角色校验访问 `/api/schedule`，Unix socket 使用固定动作、响应上限和超时。云端不可达、宿主代理缺失、真实引擎未就绪或返回合同不完整时，面板显示不可用/部分覆盖，完成百分比不被当成安全结论。

本轮本机已完成 Node 全量回归 238 项（186 通过、52 平台跳过、0 失败）、Linux 最新隔离复验 13 组共 134 项、Windows portable Python scheduler 18/18；生命周期 6/6 来自 Linux、Go `test`/`vet`/build；Windows 无 cgo，未把本地结果冒充 race 验证。v0.6.2 已通过候选 CI 37706748534、预演 37706749722、main CI 37707552435 与正式发布 37708030131；六附件已独立回取验签，并完成玄武生产升级。各环境的具体能力继续以实际代理与引擎就绪状态为准。

设置页可以安装 / 修复文件引擎，经认证、同源与 CSRF 校验后提交固定宿主任务。任务与扫描、程序升级共用管理锁；排队、维护中、完成、失败及中断分别展示。来源为玄武签名库时只维护软件包，保留库、签名和来源，停止官方写入器；来源标记损坏或缺失而保留签名痕迹时拒绝自动切源。新能力的本机测试与 Linux 门禁结果按 [验收记录](acceptance-r034.md) 分别补记，不计入历史生产验收。详见 [文件引擎维护](engine-maintenance.md)。
