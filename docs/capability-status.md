事务测试对真实 Linux 文件归档/移动操作注入故障，Docker/systemd 操作使用显式替身。Docker 部署测试在一次性 runner 使用真实容器、systemd、TLS、扫描和更新，两类证据分开报告。

病毒引擎默认安装失败时保留面板与扫描代理，并明确显示未就绪；不将安装成功当作病毒库可用。`--antivirus skip` 用于离线安装及不依赖公网病毒库的容器验收。引擎验收使用真实 ClamAV 与明确隔离的测试特征库，不能代替官方病毒库签名/下载验收。

命中文件与隔离路径仅留在本机，玄武收取摘要和检查状态。隔离记录展示的是已落盘日志状态；它不是每次请求都对隔离副本重新验签的证明。中断为 preparing/captured/restoring 时明确显示待核查；不能将记录损坏显示为“暂无隔离”。
