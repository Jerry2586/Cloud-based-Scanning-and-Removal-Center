# 签名程序分发

当前源码版本 0.3.0，候选验收中。已正式接受的版本为 0.2.1。以下是候选实现的实际命令和边界，正式验收证据见 capability-status.md。

## 玄武导入

在独立发布环境取得并核验六份正式签名附件，将它们放到玄武服务器的 root 管理目录。运行：

~~~sh
sudo xuanwu release-import
~~~

按提示输入六份附件所在的绝对目录。菜单对普通单链接文件制作稳定快照，再用固定发布公钥校验 Ed25519 清单签名、附件摘要、自解压载荷及归档身份。拒绝降级、同版本不同清单、危险文件和不可信目录。签名私钥不上传到玄武。成功后缓存放在 /var/lib/ironcurtain/cloud/releases，容器只读挂载；配置恢复包不包含该缓存。

~~~sh
sudo xuanwu release-status
~~~

显示当前可提供的版本。状态检查验证清单身份；具体程序资产在读取和下载时继续校验，不能把状态 ready 当作所有缓存字节完好的证明。

## 铁幕更新

先通过 Linux 菜单完成玄武配对，再运行：

~~~sh
sudo ironcurtain release-update
~~~

铁幕使用每节点证书、私钥、令牌与受信 CA 主动拉取；核对节点身份，不接受重定向。下载有大小和总超时限制。铁幕用自己保存的固定发布公钥独立验签，拒绝伪造、损坏和降级，再调用经过验证的 .run 安装 local 角色。已有域名、绑定地址、身份、扫描配置和病毒引擎安装模式保留；失败使用原安装事务恢复。

同版本内容相同且服务健康时安全退出。云端只提供待更新资产；网页不触发安装，规则定时同步不激活程序。玄武自己的升级仍使用固定签名安装入口，更新玄武不代表已更新全部铁幕节点。

## 认证与权限

分发路径是 /v1/releases/latest 和 /v1/releases/<版本>/<固定附件名>，只允许已登记节点或 reader 的 mTLS 加独立令牌认证 GET。撤销节点后不再允许获取。无任意路径、命令、SSH 或 Docker socket 接口。root 辅助容器只挂载该操作的临时输入输出，移除 capabilities，根文件系统只读，限制资源。
