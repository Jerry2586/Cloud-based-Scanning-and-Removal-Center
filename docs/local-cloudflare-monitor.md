# 本地 Cloudflare 配置与服务器运行监测

本机安全菜单新增第 11 项：Cloudflare 只读监测。也可运行 `appgog security-local cloudflare menu`。安装器自动安装独立采集器和每五分钟的 systemd 定时器；未配置身份、读取失败、覆盖不完整或结果超过十五分钟时，后台四项均显示不可用。

## 配置与批准

1. 在可信 Cloudflare 控制台创建只限定一个 Zone 的只读令牌，授予 DNS、Workers 路由、Zone Rulesets/Page Rules、Zone 详情和相关设置读取权限。API 拒绝时该项显示不可用，检查权限和套餐可用性。无需任何修改权限。
2. 在 Linux 安全菜单输入 Zone ID 和令牌。令牌隐藏输入，保存于 root 私有的 `/etc/appgog-security/cloudflare-read.token`；不通过浏览器、业务 .env、命令参数或日志传递。
3. 预览候选指纹，先在可信控制台独立核对 DNS、路由、规则及 HTTPS 设置，再输入精确指纹批准。批准前重新采集，配置变化或不完整时拒绝批准。以后不会自动把新变化当成可信基线。
4. 后台本机检查展示四项结论和历史告警；配置偏移发出 finding，正常合法变更也需要复核。禁止凭单个 CF 差异自动删除网站、重启业务或修改 DNS。

## 范围和权限

采集器只向固定 Cloudflare API 发 GET，正常 TLS 校验，禁止重定向和环境代理。最多三十秒、三十二请求、单响应 1 MiB。DNS 最多四千条，规则集最多十六个，Page Rules 最多一百条；规则集按游标完整读取（最多四页）；游标重复、分页未完整覆盖或超限均为不可用。基线和报告只存摘要与数量，不保存 DNS 内容、规则表达式或 Token。

只监测单 Zone 的 DNS、Workers 路由、Zone Rulesets/Page Rules，以及暂停状态、名称服务器、SSL 模式、强制 HTTPS、最低 TLS 和安全级别。不检查账号登录、会话、令牌清单、账号级规则或 Workers 脚本源码。账号失陷仍需账号审计和独立管理通道核验。

业务安全代理保留 AF_UNIX 网络限制，不接触 CF 令牌。只有独立只读采集器能够联网。卸载移除采集器和定时器，保留私有身份、基线与报告，便于受控重装。失败升级恢复原程序、服务和定时器状态，不自动更换可信基线。

## 服务器运行检查

新增宿主 /proc 执行路径检查：最多 2048 个进程、三秒，只读取执行文件链接；临时目录运行或执行文件已删除显示 warning。进程退出和内核线程可能没有 exe，权限不足或超限显示不可用。不读取命令行、环境变量、进程内存；不自动杀进程。

新增 systemd failed 服务/定时器检查：固定命令、五秒及 256 KiB 输出上限，最多 128 个单元。失败状态显示 warning；异常格式或超限显示不可用。它不能替代登录审计、内核检测、依赖漏洞扫描或数据库内容审核。

完整报告仍限制为 32 KiB，API 最多接收 24 项；历史先缩减，检查项过大则整份报告不可用，不静默丢弃检查制造健康结论。
